خطوات الحصول على APK:
1) أنشئ حساباً في github.com (مجاني).
2) أنشئ مستودعاً جديداً (New repository) باسم mutarjim-app.
3) اضغط "uploading an existing file" وارفع كل محتويات هذا المجلد
   (مع المجلد المخفي .github — إن لم يظهر لك، استعمل GitHub Desktop أو ارفع من الحاسوب بالسحب والإفلات).
4) انتظر 5-10 دقائق: تبويب Actions > Build APK.
5) افتح آخر تشغيل ناجح، ثم من Artifacts حمّل mutarjim-apk (ملف zip فيه app-debug.apk).
6) انقل app-debug.apk إلى هاتفك وثبّته (اسمح بالتثبيت من مصدر غير معروف).
لتحديث التطبيق لاحقاً: استبدل www/index.html ثم ارفعه وسيُبنى APK جديد.
